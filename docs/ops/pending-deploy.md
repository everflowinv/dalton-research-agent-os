# 部署与恢复说明

当前能力和未解决资料缺口见 [项目状态](../PROJECT_STATUS.md)，版本变更见 [变更记录](../../CHANGELOG.md)。本页保留稳定入口，历史部署指令、机器配置与逐次操作证据已私有归档，不作为新的部署计划。

发布使用冻结源码、依赖锁和已验证安装包，在原配置、权限与预算下切换。切换前停止新任务并等待在途任务、费用及写入结算，保存冷备份；切换后核对服务、源码身份、真实研究结果与页面。恢复使用当次备份和明确的原 release，不从旧记录中的机器路径猜恢复目标。

研究任务的缺材料、严格核验拒绝、费用停放和产品等待结果在工作台保留。代码安装成功不代表研究已完成；日常研究不需要重放这里的历史运维操作。管理员的实际执行计划和收据应保存在主机私有目录。
