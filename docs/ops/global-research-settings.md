# 全局研究设置

管理员保存模型顺序、思考强度或研究预算后，系统先保存本机共用设置，再通过各项目原有写入服务发布本地授权版本。保存不会冒充项目所有者；共享访问沿用独立共享主体。暂停或离线项目列为待应用，恢复调度前核对设置。未核对完整时不发起新付费模型调用。

运行中的调用保留原 Work、授权和结算。新调用使用独立的配置副本，从同一模型策略血统读取已发布的新引用和凭证槽；既有共享单次调用预算快照不改。旧结果与账本不改写。不同项目的原预算池和研究目标不会在迁移时被复制或合并。

## 首次初始化

在安装新包并配置管理器后执行；研究调度暂停时也可初始化，无须临时开启写入服务。使用新安装包的解释器，不设置源码 `PYTHONPATH`。`MANAGER`、`STATE` 是现有管理器配置和模型配置源项目目录，`ACTOR` 是本次操作的真实 `human:` 主体。

```sh
env -u PYTHONPATH "$RUN_PY" -m dalton_core.host_research_settings \
  --manager-config "$MANAGER" --source-state-dir "$STATE" --actor-ref "$ACTOR"
env -u PYTHONPATH "$RUN_PY" -m dalton_core.host_research_settings \
  --manager-config "$MANAGER" --source-state-dir "$STATE" --actor-ref "$ACTOR" --apply
```

第一条只预览；第二条仅保存持久设置，不触发模型调用或跨项目写入。若已有设置，必须显式给出当前 `--expected-hash`，否则拒绝覆盖。正常控制器或之后的管理员保存会通过写入服务完成待应用部分。

初始化从当时真实模型策略读取共同顺序，并强核对两项目的预算授权。当前共同每日上限用于新建项目的目标草稿和正式发布；没有正式目标的既存空项目也在首次草稿时读取这些默认值。共同上限不同则拒绝初始化，不取最大值。不在初始化时改已有研究预算。之后明确保存全局研究预算才更新所有项目和未来默认值。

预算草稿绑定共用设置版本；确认时如果版本已变化，必须重新起草。正式预算发布走原政策、任务授权、研究规则、研究目标和每日预算账本引用链。次数上限可以为零；新共享每日策略 0.2 会实际拒绝相应的新准入。历史 0.1 的格式、零值限制和哈希保持不变。每日费用仍要求正数。

## 只读核对

管理员页面显示共用设置版本与尚待应用项目。内部只读接口 `host_research_reconcile.status(manager_path)` 核对实际注册配置、策略哈希、正式目标和共享每日策略，不把保存回执当作所有项目已经应用的证明。重入复用相同设置，不重复发布相同本地版本。

共用设置保存在管理器 `host_root` 下的 `shared-research-settings.json`，历史版本在相邻 `shared-research-settings-versions` 中。文件由本机用户管理，保存有 CAS、文件锁、原子替换和落盘校验。源码测试使用独立合成项目，不接生产数据库或模型服务。
