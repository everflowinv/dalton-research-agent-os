# ADR 0022: One research-question authority with bounded maintenance

Date: 2026-10-10. Status: implemented and deployed; live research outcomes remain separately verified.

ResearchQuestionBacklog owns research-question state. Agenda freezes candidate links to exact backlog versions and no longer creates research_question_versions/pointer shadows. Historical candidate foreign keys and original hashes remain unchanged; append-only migration receipts either link an exact canonical question or explain supersession/retirement. The canonical identity namespace is versioned. Only unambiguous named numeric fact lookups with an exact period/accession, or a writer-authorized explicit closed key, merge across wording. Mechanism questions retain their normalized text identity. Each change appends an immutable content version. Selected/terminal questions cannot change frozen answer/source requirements.

An answer must bind reverified formal claims, the exact issuer, checkable criteria, exact annual/quarter authority and each required filing type/period through the accepted claim's supporting evidence and recorded SEC metadata. A question's own source list is never evidence. Uncheckable criteria and unproved fiscal periods refuse; model assertions do not substitute for these gates.

Maintenance appends readable terminal reasons for operational/out-of-scope questions, protects live Scheduler leases, and attaches otherwise unbound questions to zero-attempt/zero-dollar MaterialRequests. Historical shadow migration is idempotent and append-only. Staged candidates without a review expire after 24 hours, preserving exact claim/evidence hashes, reasons and formal-promotion protection. Expiry is neither human rejection nor automatic promotion.

Across-loop probe decisions freeze exact local source material hashes. Identical query/material cannot repeat terminal scans; changed exact local evidence/document authority can unlock the query under the original admission/budget checks. Two unavailable outcomes join the MaterialRequest ladder with no new paid-search authorization. Missing source bytes remain conservative. Alias/name relevance rechecks are keyed by the declared name set.

Routine document gates automatically admit already-read held inquiries, allow at most two stage repair links for contract failures within the existing daily ceiling, and withdraw expired holds only with exact deadline observations and no live lease/pending recovery. Unknown-send retries, provider fee limits and new paid retrieval retain their existing human gates.
