# ADR 0023: Append-only repair of existing industry research methods

Date: 2026-10-10. Status: implemented and activated; prepared research text still requires normal independent verification.

New-workspace specialization does not repair an existing generic method. The repair planner reads exact mission, constitution and driver-pack versions, verifies their canonical hashes and specializes only registered generic industry methods. Custom methods remain unchanged. The plan freezes source versions, universe, owner budgets and deterministic new version references. The CLI defaults to a read-only review; applying requires an exact plan hash and explicit human actor.

Applying appends pack, constitution and mission versions and versions the output policy references. Original records and prior policy snapshots remain readable with their hashes. Every material task is verified before any authority append. Recovery resumes the same deterministic versions after interrupted policy materialization; an exact completed receipt makes repetition idempotent. The repair does not dispatch a model, connector, message or deployment.

Supply-and-cost tasks use the existing canonical, nonretired company-material query and exact statement-line projections. Each prepared body records source hashes, claim hashes, original periods, source classification and clearly identified inferences. Missing classification or canonical material produces an explicit material-required result. Prepared text is pending independent verification and is never presented as a formal publication. Standard dossier planning and input construction independently prove the corrected structure can select the unit and supply its material.

The isolated Hyperscalers replay activated sixteen drivers and generated held-material drafts without changing historical authority or fee permissions. Later configuration activation is distinct from formal dossier publication; prepared text must still pass normal source and independent verification.
