## 研究模块

| 模块 | 分析师可以做什么 | 系统保存什么 |
| --- | --- | --- |
| 研究项目 | 设定行业、公司范围、重点问题和预算；建立新项目 | 目标的每次修改、覆盖名单、来源和预算设置 |
| 资料与出处 | 阅读披露、纪要和研究资料；从结论打开原文 | 原始资料、获取记录、公司、期间与引用位置 |
| 公司与行业研究 | 查看业务分析、本所观点、反向观点和分歧 | 档案与行业框架的历次版本、采用的事实和待补问题 |
| 财务预测 | 检查历史与未来季度、业务驱动和现金流假设；导出底稿 | 申报口径、模型规格、假设、公式和计算结果 |
| 情景估值 | 比较悲观、基准和乐观情景；调整概率并说明依据 | 情景条件、概率、估值依据和修订记录 |
| 问答与决策 | 围绕行业或公司提问、继续追问；处理需要判断的事项 | 问答上下文、引用和分析师的决定 |
| 跟踪与复盘 | 查看事件、预测偏差及后续问题 | 事件判断、差异原因、后续任务和周报 |
| 运行管理 | 查看任务、模型、资料来源、费用和项目状态 | 调用费用、设置变更及项目创建、暂停、归档等记录 |

各项目分别保存研究记录，共用模型顺序、思考档位和上限由管理员统一维护。两个项目的投资备忘录均保留 Grok 4.7 第一，文档事实抽取保留 Muse Spark Contributor 第一。不能立即应用的项目显示待同步，恢复执行前先应用最新设置；页面可查看当前生效顺序和实际使用的服务。

周报正文与送达记录可在工作台查看。研究进展周报汇总项目进展、资料缺项和待处理事项；研究周报根据已有行业研究与出处生成。当前固定排期为纽约时间每周四 07:00。

## 已完成的验证

工作台的五个主要入口已逐页检查：研究总览、公司研究、智能投研问答、待办决策、投研规则与设置。检查覆盖主要按钮、出处查看、键盘操作和 320 像素窄屏。公司档案关闭后可返回原按钮，ACN 研究报告 HTML 已实际下载。问答与修改操作在隔离项目中测试；新项目创建、暂停、归档、恢复和删除也在隔离项目中走完了实际服务流程。

财务模型的隔离回放覆盖连续八个季度、季度与财年口径、年度 EPS、业务分部、债务利息、折旧摊销、现金流及情景估值。DXC 新申报的来源对应关系已修复，396 行财务上下文通过读取校验。SPY 十年价格历史已入库，共 2,514 个交易日。

研究规划现保留 IT 服务的全部五家公司和 Hyperscaler 的全部四家公司，以及未回答问题所需要的原文。数字任务绑定的旧版原文和最新版本可同时读取；文档抽取的已付费调用暂遇费用写入冲突时，系统保留结果并登记待补结算项。
