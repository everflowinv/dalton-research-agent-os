## 研究模块

| 模块 | 分析师可以做什么 | 系统保存什么 |
| --- | --- | --- |
| 研究项目 | 设定行业、公司范围、重点问题和预算；建立新项目 | 目标的每次修改、覆盖名单、来源和预算设置 |
| 资料与出处 | 阅读披露、纪要和研究资料；从结论打开原文 | 原始资料、获取记录、公司、期间与引用位置 |
| 公司与行业研究 | 查看业务分析、本所观点、反向观点和分歧 | 档案与行业框架的历次版本、采用的事实和待补问题 |
| 财务预测 | 检查历史与未来季度、业务驱动和现金流假设；导出底稿 | 申报口径、模型规格、假设、公式和计算结果 |
| 情景估值 | 比较悲观、基准和乐观情景；调整概率并说明依据 | 情景条件、概率、估值依据和修订记录 |
| 问答与决策 | 围绕行业或公司提问、继续追问；处理需要判断的事项 | 问答上下文、引用和分析师的决定 |
| 跟踪与复盘 | 查看事件、预测偏差及后续问题 | 事件判断、差异原因、后续任务和周报 |
| 运行管理 | 查看任务、模型、资料来源、费用和项目状态 | 调用费用、设置变更及项目创建、暂停、归档等记录 |

周报正文与送达记录可在工作台查看。研究进展周报汇总项目进展、资料缺项和待处理事项；研究周报根据已有行业研究与出处生成。当前固定排期为纽约时间每周四 07:00。
