## 核心发现摘要

本次针对 Dalton Cockpit 进行了逐页面（6个主视图 + 5家公司7大Tab + 5个二级模态窗 + 独立周报页）和逐元素的真实浏览器（Playwright）无头渲染、DOM、网络、控制台和数据流深度检查，核心发现如下：

1. **功能实现与阻塞问题 (P0)**：
   - **每周复盘正文被误杀**：`renderReflection` 被前端 `finalResearchReady` 全局门禁静默遮蔽为“正文正在检查文字表达，完成后会显示。”，尽管后台已生成地道中文。
   - **公司档案在 ACN、DXC 长期阻塞且导出为空**：虽已起草全部 12 个单元，但因后台 publication worker 受 SQLite `database is locked` 退出，导致网页端与导出 HTML 中均为空占位符。
   - **公司模型详情交互破坏性覆盖**：在公司详情抽屉点击“查看模型详情”，直接替换抽屉 DOM，导致丢失公司 7 个 Tab 上下文，无法返回。

2. **语言非通俗易懂中文 / 代码变量泄漏 (P1)**：
   - **行业框架章节标题代码泄露**：直接显示 `causal_chain:0`、`causal_chain:1`、`causal_chain:2`、`causal_chain:3`。
   - **情景触发条件夹杂英文变量与枚举**：出现 `Revenues同比%`、`Operating income同比%`、`THESIS_BROKEN`、`≥ 1 count`。
   - **结论库与待办审批技术黑话过多**：存在大量英文抽取模版句，待办审批中甚至直接出现未翻译异常 `PublicTransportResponseTooLarge` 和终端命令。

3. **显示 Bug 与数值规范问题 (P1/P2)**：
   - **已发布产物版本号问号 Bug**：CTSH、EPAM、IBM 所有已发布产物版本一律显示为 `第 ? 版`。
   - **金融金额无千分符、无单位**：利润桥出现 11 位裸数字 `69672977000`，且整列暴露 `us-gaap:...` 原始 XBRL 标签；情景出现 `200000000`。
   - **数据源抽屉 CSS 文本粘连**：`.lane small` 缺乏块级 display，导致“可获取内容：日程连接：本机连接器目录未登记”挤在同一行。
   - **待办审批指引前往不存在的页面**：“在哪里做：运行状态 页”（实际无此导航）。
   - **每周简报残留旧称**：“← 返回驾驶舱”与未处理的 Discord 内部通道 URI。
