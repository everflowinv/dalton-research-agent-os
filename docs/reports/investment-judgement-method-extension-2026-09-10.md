## 1. 同一研究过程，更明确的判断结果

行业理解仍研究长期供需、竞争、商业模式和资本周期，财务模型仍可预测多年。基金持有期限与模型预测期限是两件事：即便价值在三年后兑现，也须回答为何市场可能在未来不超过十二个月内重估它。不能把所有初步研究都强制成催化剂交易，也不能用三年后可能发生的事直接冒充十二个月收益。

在已有 Thesis、DebateMap、模型和 Memo 上补一份持续更新的投资判断：当前立场、期限、主要赚钱来源、市场目前如何理解、我们的判断、价格兑现路径、上下行情景、最强反证、下一项应核实的问题。允许明确写“好公司、当前价格缺乏吸引力”“值得跟踪、尚未形成观点”“观点正确但时间窗口不匹配”。单一收益来源也可构成机会，不强行要求三者共振，不为了制造 variant view 而反对市场。

## 2. 盈利、预期与倍数必须使用一致口径

三个维度分别研究：

- 盈利增长：分部量价、份额、业务组合、产能/利用率、成本、经营杠杆、税息和股本如何带来每股盈利/现金流变化。区分可持续经营变化与一次性、收购、汇率、会计口径。
- 盈利预期上修：对同一目标财期，市场原先预计什么、我们的驱动假设为什么不同、哪些证据会推动市场改预测。正确预测与股价赚钱并不等价：还要看买方是否早已预期、事件后价格是否已经反映。
- 估值变化：低估正常化、新溢价形成、风险/折现率变化分别论证。历史分位低不是充分理由，要比较增长、ROIC、杠杆、会计口径和行业状态是否仍可比。

正盈利且适用同口径 forward P/E 时，可建立以下精确价格桥。令 t0 为当前时点、T 为不超过十二个月的观察时点；F0 为当前价格采用的前瞻盈利窗口，FT 为 T 时采用的同长度/同口径前瞻窗口；E0(F) 为 t0 冻结的该窗口预期，ET(FT) 为 T 时的同窗口预期（事前为显式情景，事后为真实快照）。

```
P0 = M0 × E0(F0)
PT / P0 = [E0(FT) / E0(F0)] × [ET(FT) / E0(FT)] × [MT / M0]
             原有预期的时间滚动         同一财期预期修订         倍数变化
```

这不是把增长的全部因果机制都归为日历滚动；业务驱动仍在底层模型解释。其作用是避免既算“我们的全部盈利增长”，又把同一盈利超预期再加一遍。事前第二项是上修潜力，不是已实现 revision；退出时采用我们预测的盈利也须说明市场何时、为何接受该盈利，不能默认届时必然认可。

教学例：当前 20×10=200；t0 对退出估值窗口的 EPS 为 11，我们的情景为 12、退出倍数为 22，则目标 264、价格收益 32%。三个因子 1.10×(12/11)×1.10=1.32，不能直接相加为 29.1%。展示瀑布图必须披露归因顺序或对交互项使用确定规则；不把会计恒等式声称为因果识别。

分红单列到总收益；回购若已通过稀释股数进入 EPS，不能再加一遍回购收益。EV/EBITDA、EV/revenue、SOTP、银行 P/B 等保留行业适用方法，净债务/股数转换必须明确。亏损、零值、不同财期或不同盈利定义不适用上述比例时，明示缺口或采用显式批准的方法，不自动切换得到漂亮数字。

## 3. 市场预期需要分层，而不是一个“consensus”字段

并排保留：卖方数字共识、公司指引、具名买方预期证据、销售台对客户预期的观察、社媒参与者观点，以及我们自己的预测。每条有发布时间/可用时间、财期、口径、身份、原文和置信边界。我们的 house view 不叫 buy-side consensus；一份销售笔记也不能代表全部买方。

反解价格隐含假设必须声明锚点：给定倍数推盈利，或给定盈利推倍数，再形成可接受的假设区间。一个价格不能同时唯一识别增长、利润率、折现率和终值。市场数据不足时可以提出条件性判断，不能输出伪精确的“市场已经定价 73%”。

管理层指引风格从既有 guidance_profile 继续深化：同期间同口径的初始指引、每次修订、最终业绩、外生影响和业务状态。经常 beat 不等于市场没预期到 beat；比较卖方与可观测买方在财报前已经吸收多少。历史偏差只能成为可质疑的预测假设，不机械地给每期盈利加固定比例。

## 4. 叙事的研究单位是可检验的解释

已有 DebateMap 保留。对每条关键 debate 补充：谁在讲、解释机制、市场采用的估值视角、支持/反对证据、传播范围、可能的新 debate、哪些变化会使原解释失效。

叙事跟踪分开看四条链：传播与接受；真实经营结果；盈利预测变化；估值/价格变化。可能只传播却无经营效果，也可能经营先变而市场尚未注意，或叙事已拥挤、利好兑现反跌。不能把这些状态压成一个热度分数。

观察萌芽、扩散、主流化、拥挤、反转时按来源群体和持续性比较；同一帖子被转载十次不算十个独立信号，公司重复自己的话不算外部采纳。X/雪球可发现早期观点和语言迁移，sales notes 可观察客户争议，卖方可观察模型与覆盖框架变化。未连接/shadow 来源如实列缺失，不写成覆盖完成。

允许提出早期假说：例如某种业务可能从周期项目收入被重新理解为持续性平台收入。随后列出必要经营条件、谁先采纳、哪些指标能验证、失败路径和估值情景。非线性须说明阈值/机制：经营杠杆、融资约束解除、业务分类/SOTP权重变化等；不能因“可能很大”随意乘倍数。证据不足可以有有条件的判断，不要求每次都编造数值概率。

利率等宏观因素按公司解释折现率、再融资成本、客户需求、汇率等不同通道。历史事件研究可提供线索，但共同波动不证明因果，旧利率敏感性不能无条件外推到新业务/杠杆结构。

## 5. 研究工作流如何消费这些判断

- Initial Screen：保留行业/公司基本认知，初步列出可能的盈利、预期、估值驱动与关键未知；不要求此时已有完整目标价。
- 完整覆盖与建模：将关键 driver、市场隐含假设与 ours/street 差异逐项接到年度/季度模型，建立合理情景而非任意 bull/base/bear 增减百分比。
- Thesis / Memo / Conviction：基于上述材料清楚表达立场、<=12个月的兑现路径和风险回报。高确信度仍需充分论证；不自行新增“必须两项共振”等基金规则。
- 每日跟踪：标明新材料改变了事实、我们的判断、市场预期还是估值；生成应核实的问题和预测/观点候选，沿用现有权限。
- 财报与周会：冻结事前判断，对照实际、预期修订和价格反应，分别回答业务判断对错、预期判断对错、估值判断对错、时间判断对错。赚钱也可能是判断错却市场整体上涨，亏钱也可能是路径尚未发生；不只按盈亏奖励模型。

优先搜什么由已有 ResearchTask/Planner 消费具体缺口：哪个未知最可能改变观点、哪种证据能区分两个解释、十二个月内是否可验证、成本和数据可得性如何。保留广泛行业学习，不把探索预算全部压给当前持仓催化剂。

## 7. Owner 进一步确认：长期认知基础上的持续贝叶斯迭代

Owner 明确：长期看法、护城河、业务本质至关重要，是基础；新增能力解决如何把认知变成投资建议和赚钱能力，并随每日股价/新闻持续更新。不是取消长期研究，也不是每天强行改变观点。

分别保留三条状态链：公司/行业认知、市场预期/叙事、当前价格下的投资吸引力。价格上涨而公司认知不变，剩余预期回报可能下降；价格下跌也不自动证明基本面恶化或股票更便宜。重大信息可快速改变长期判断，普通重复消息不应制造更新。

每次更新记录：先前具体假说与版本；本次新证据及可用时点；至少相关的替代解释；证据在不同解释下的区分力；支持/削弱/无更新及理由；更新后的判断和不确定性；对盈利/预期/倍数/兑现时间分别的影响；下一项验证。缺少可校准的基率或似然时用可解释的定性更新，不让 LLM 凭空输出数学精确的 posterior。可定义互斥且覆盖的情景、具备真实校准样本时才用数值概率并留版本。

同源转载与由同一数据衍生的卖方评论不是独立证据。价格反应是关于市场定价机制的观察，存在多种解释；它既用于提出假说，也须避免同一波价格变化被再次当作独立基本面证据。例：超卖方预期但下跌，应比较买方门槛、提前定价、指引/业绩质量、宏观/行业共同冲击等；没有足够证据时保留未决解释并派研究。

已有事件流、预测修订、ThesisRevisionCandidate、AnalystJournal 和周会复盘承接这条更新链。输出始终可以追问“相较上次为什么变/没变”；只有数据/判断/价格变化真正影响投资吸引力时才调整建议。研究建议与真实交易执行保持既有分工，不新设审批门槛。
