# Financial-note planner target review — 2026-09-11

This change adds one optional typed target to the existing
`directed-document:0.1` strategy:
`financial_note:diluted_eps_numerator:0.1`. The planner may only copy the full
closed target object from the selected readable document's inventory. The
target binds an exact acquired SEC 10-K, immutable statement filing hash, and
one annual period supported by dimensionless filed diluted-EPS and diluted
weighted-average-share facts.

Admission replays the archived plan, inquiry identity, registered original,
active mission/company ownership, and current statement filing before any
research Work can be derived. A target added to a later plan has a distinct
identity; an old targetless qualitative inquiry retains its historical bytes
and behavior. Invalid optional statement authority removes the target without
disabling ordinary qualitative reading of the original.

The target authorizes retrieval of cited note text that explains the diluted
EPS numerator. It is not numeric authority, does not calculate a numerator,
does not alter a forecast, and cannot establish quarterly applicability. A
separate post-promotion evidence resolver must replay the promotion and cited
passages before a structure consumer can use the qualitative note evidence.

Validation on the isolated worktree ran 167 strategy, inventory, planner,
research-task, and mission-document admission/execution tests successfully.
No live state, provider, model, or network operation was used.
