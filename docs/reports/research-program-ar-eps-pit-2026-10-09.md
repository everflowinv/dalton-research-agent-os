# 年度与每股证据、双口径估值和收益桥

技术设计与验收摘要，2026-10-10。隔离测试和历史回放用于核对合同与兼容性；不等同于当前公司研究已完成。原始研究材料、运行账单及逐文件收据私有留存。

年度投影绑定完整财年四季网格，区分实际、混合、预测与不完整。缺整年/单季不当作零或预测，历史年度 EPS 优先直接披露事实；旧投影按原算法重放。裁剪前来源期间保留，旧记录没有该信息就标来源覆盖未知。

股份和普通股分子只能由持有且验原始字节/CIK的 companyfacts 精确匹配 accession、filed、form、起止期、概念、单位与类股后补充。补充形成独立 context snapshot 和 line refs，不能覆盖申报行或将集团股份映给特定类股。模型输入/proof 按具体 context 读取。

中期 TTM 使用普通股分子和同期间按天加权股份，不直接相加季度 EPS/股份；历史版本按实际公开日可得性截断，不能把重述值配最早披露日或把当前股数回填历史。估值分位保留样本数量与窗口。

GAAP PE 与真正 core 税后 PE 分开。core 税额必须有明确 authority；无税效分配仍可给 core 营业利润，但 core EPS/PE 缺失。GAAP 税率推算若合格，只能另称营业税后近似并显著说明假设；重大营业外损益或异常税阻断近似。收益桥不使用收入×历史净利率伪造 core EPS。

股息按实际支付日、币种、类股和完整覆盖窗口绑定原始证据。缺失与确认零分开，覆盖不足只给价格回报，总回报缺失；不使用 ex-date、财年 DPS 或现金流÷股份代替区间实收。

历史七公司只读回放复核每股/TTM/PIT 及类股身份，完整实付股息 authority 缺失的样本均保留总回报缺口。合成测试覆盖完整财年、公开日、重述、missing/zero、税口径、独立 snapshot 和旧 wire/hash。新输入改变哈希后须正常规格更新和模型重算，不移贴旧认证。
