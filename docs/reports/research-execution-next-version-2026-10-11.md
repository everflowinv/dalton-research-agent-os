# 下一版本：建模、预算与研究执行

本报告记录 2026-10-11 的运行观察和 v0.11.2 修复。当前发布候选包保持不变；下面的代码验收不表示线上研究已经完成。

## 优先事项

1. **Amazon 模型。** 原答案将会计净利润直接接入稀释 EPS，一次修正又把净利润本身改成 EPS 分子角色，使税前利润减税费的公式失去合法输入关系。新起草与修正说明要求保留净利润，再建立有申报依据的 EPS 分子衔接行。校验错误现在指出具体公式、项目和角色。规则版本变化会形成新任务，旧失败答案、暂停记录与费用保持原样；最多一次结构修正的限制不变。
2. **规划输入。** IT 服务的必要状态为 64,844 字节，旧程序的 64,000 字节存储限制挡住了管理员允许的更大输入。新的有限存储上限为 128,000 字节，仍遵守任务输入预算的保守估算与实际准入检查。旧长度拒绝需要在限制改变后重新检查；其它失败不因此重新付费。
3. **模型输出。** 事件判断默认输出上限改为 32,768，初筛改为 64,000。线上分别仍为 8,192、16,000，需在下一版本部署时用正常共享设置接口同步，现有和新建环境共同采用。事件判断的 9,143 token 输出曾触发一小时暂停使用，随后使用第二顺位 Opus；Amazon 初筛返回了 52,335 token，也因旧上限被拒绝。金额上限与模型顺序保持现有设置。新预算形成新任务身份，已运行任务的预算和账单保持原样；初筛可能需要等待现有一小时空闲检查周期。
4. **材料额度。** ACN、EPAM 的追加批准均有效，当前每项已有 1.00 美元、11 次检索额度，已记账 0.105 美元、11 次检索。新提示保留批准记录，只申请真正不足的金额或次数，并按本轮剩余来源估计追加量。批准后立即根据当前额度隐藏旧拒绝；下一轮真实新增短缺具有独立标识。

5. **保存上限后的任务恢复。** CTSH 的超限发生在旧 16,384 token 任务，实际输出 17,472；管理员已将上限保存为 32,768，但原调度身份没有包含共享预算，因此停在旧失败记录。模型起草现在把有效预算纳入配置判断与启动任务；保存相同值或修改其它环节不重复启动。配置在检查与启动之间变化时本轮不派发，下一轮读取新配置。已经运行的任务按启动时的配置记录结果，旧失败不会污染新上限；历史任务、费用与财务内容检查保留。

## 观察到的检索问题

明确提到 10-K／10-Q 的问题被当作普通问答需求，外部来源选择了电话会及专家访谈，SEC 申报来源反而被判为不适用。中文复合问题还被整段用于英文原文的关键词覆盖检查，相关段落因覆盖不足被全部过滤。

只读复查发现 EPAM 的 2026-08-06 10-Q 已在库中，营业成本、销售与管理费用的英文术语可以命中；ACN 的订单披露也有相关原文。单个词命中、其它期间或其它文件命中，以及被宽泛关联到目标公司的材料，都不足以宣布原问题已回答。检索修复保留公司、文件类型、选定文档及每个子问题的缺项；财政期间或文档版本尚未证实时保留部分找到状态。显式申报需求会选择 SEC 来源，逐项检索英文术语；关联到其它公司或其它申报类型的材料不能满足需求。免费复核找到的部分材料也会按确切文本版本交给后续阅读，不增加检索费用，不将整题标为完成。链接验证失败时，原请求状态与复核机会保持不变。

两项真实请求的免费只读复查中，EPAM 找到十二段合格相关原文，仍缺利润率与一次性项目；ACN 尚无合格 10-K 原文。

## 验证边界与上线次序

Amazon 的两份历史模型回答及原始任务已离线读回并核对哈希，旧错误仍会被财务校验拒绝。隔离测试证明新任务身份排除旧修复答案，原身份仍能准确回放；这不等于已经生成新的可用 Amazon 模型。

预算回归覆盖已有批准生效、零金额追加次数、一次建议覆盖剩余来源、重复显示抑制、新一轮短缺和不足一美分的向上取整。没有执行追加批准、外部检索、付费模型调用或线上设置修改。

建模、规划、材料预算、模型调用及初筛上限的联合回归已通过 752 项测试（51.439 秒）。测试中的高单价模型使用显式的小输出额度，保留对真实预算约束的检查；实际默认上限另有独立验证。检索、材料预算、规划与投资判断的整合回归另通过 321 项测试（28.608 秒）；随后补充的免费复核事务边界通过其专项回归。共享预算变化后的模型调度恢复通过 102 项相关测试及独立复核，包含在途保存和启动前设置变化。

02:31–02:34 UTC 的五次补充观察中，九家公司的模型规格、正式预测、档案与最新交付物均未变化；Hyperscaler 在 02:34 新增一份计划。02:37 按该计划查验，尚无新的定向阅读申请，不能把计划增加计为新的研究答案。

v0.11.2 整合后的 43 个相关模块共 1,073 项测试通过（84.989 秒），覆盖预算变更、在途保存、启动前变更、旧费用保存、检索交付、财务结构和工作台配置读取。此结果是代码验收；线上恢复和新研究产物另行观察。

当前发布完成后，再部署下一版本、同步事件判断与初筛共享上限，并观察正常任务是否产出新计划、有效模型规格和正式预测。验收以这些成果及其出处为准，服务心跳单独记录。
