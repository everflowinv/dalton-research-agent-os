# Joint annotation diagnosis and executable source needs

The normal model-spec lane now diagnoses a finite set of fields from the exact original answer: missing or empty required expense explanations, an empty optional reason on an already valid bound cost slot, and the existing independent annual shares/EPS or unsupported OCF-base settings. It does not diagnose every financial error. The original root, producer question and task identity remain unchanged. Structured repair 0.16 uses the original unused single ordinary slot; any prior paid, failed, unknown or active repair still consumes that slot. Old independent-settings 0.1, typed-field and maintenance proof readers remain unchanged.

A private shape view supplies temporary explanation placeholders and omits recognized empty annotations solely to inspect independent settings. This view is never an accepted answer, stored specification or numerical input. The proof hashes the original body, original field presence and values. The model must return the whole answer with only the enumerated paths corrected. The whole-body guard rejects other additions, deletions, formulas, sources, values, periods, units, driver definitions and array order. Normal full parser, financial history/DAG/cash validation and owner persistence still run. A failed full validation cannot purchase a second slot.

A declared external driver with no bound basis and no execution formula is a real source gap. The lane refuses an explanation-only paid repair. After exact succeeded original Work/formal/receipt/route/all settlements, current mission permission and current frozen state/prompt are rebuilt, it opens regular material requests for each undeclared operating metric and each *proved numeric-context quarter*. The schema bounds this to ten metrics times eight quarter windows. Acquisition uses the existing indexed/SEC/AlphaEngine/web queue, budgets and source permissions. Repeated registration deduplicates normally. No new source permission, model grant, financial authority or schema table is introduced.

These material requests describe acquisition needs, not proof that a company discloses the metrics. A matching paragraph is material availability, not a admitted model quantity, price, proxy, formula or forecast. Numerical/source-period/units/full-dimensions admission and a normal source-backed model definition remain necessary. Missing unproved quarters continue their existing unit/history acquisition paths; filing report dates are not substituted for data periods. Declared execution errors outside this finite external/null-basis scope retain their original refusal paths.

Actual read-only qualification on the original current ACN Work found three allowed paths: omit its empty optional reason, shares annual semantics, EPS annual semantics. Counterfactual choices pass complete financial validation; the model has not actually returned those choices and no production specification was written. Its original 92,224 micros and unused ordinary slot remain unchanged. Current CF has six omitted explanations and a genuinely unexecuted external driver: four operating metrics times **three proved quarter windows = twelve** source descriptors. Its original 215,952 micros remain unchanged. No production material requests or model calls were made in these observations.

Focused regressions cover two companies, joint multi-error one-call repair, exact source queue consumption of a held filing, normal owner spec persistence, restart/cross-day free replay, unknown/failed/active slot locks after budget changes, current permission/source/raw/settlement tamper, whole-body drift, closed refs, overflow, and a single normal lane validation wake followed by a stable hold on true remaining defects.
