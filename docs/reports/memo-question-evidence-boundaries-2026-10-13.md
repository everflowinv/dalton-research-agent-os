## 十二问的可执行范围

| 问题 | 普通研究可取得或计算的内容 | 必须保留的边界 |
|---|---|---|
| q01 业务简述 | 公司申报、官网、持有原文与已核实论点 | 资料存在不等于所需事实已核验 |
| q02 收入/盈利驱动 | 原报表、分部/经营指标、已核模型与趋势 | 不补缺成员、单位或分部调节残差 |
| q03 隐藏假设 | 正式模型假设、敏感性、管理层指引的对照 | 推断必须有引用并说明不确定性 |
| q04 股东价值创造 | 三年申报中的回购、分红、股数；具备明确口径后的 ROIC、复权收益与明确篮子的比较 | ROIC 分子/分母口径与期间需单独证明；宽基不是行业篮子；复权价格不能再加一次股息 |
| q05 三年事件/价格反应 | 已有价格序列、真实事件日期、同日期价格窗口和基准回报 | 日期不能猜；观察窗口不是因果；有限事件集不是完整三年事件研究 |
| q06 可跟踪高频指标 | 明确已披露的指标、频率、出处；持有专家/行业材料；普通新材料请求 | 不将季度数字写成月度序列，不假设专有面板已接入；问题中的示例不意味着所有类别都必须有数据 |
| q07 一致预期/多空观点 | 正式一致预期、持有研究/专家材料、原文引证 | 数据商/卖方一致预期不能冒充买方共识 |
| q08 方向与 variant view | 有来源的模型差异、假设明确的研究建议 | 研究仓位情景不是用户真实持仓或实盘授权 |
| q09 事件路径 | 强日期/来源的催化日历、公告与假设验证点 | 预测日期与已确认日期必须区分 |
| q10 时间跨度 | 有证据的催化窗口与研究期限 | 不冒充用户账户投资期限、流动性约束或已执行订单 |
| q11 是否/如何对冲 | 基于已核风险的研究情景与替代触发；具备强价格口径后可另做贝塔/比率计算 | 用户真实持仓、风险限额、交易权限不能由公司材料推知；当前没有期权数据源，不能编造 IV、报价或合约成本 |
| q12 风险/承受能力 | 公司风险、模型情景与明确假设的研究风险预算 | 不断言用户能承受某损失；实际承受能力需用户信息 |

## 当前 META 四个缺口

* q04：旧答案要求 FY2023–2025 的 ROIC、回购、分红、摊薄股数及相对行业篮子的三年股东总回报。年报指标可以走现有持有原文的正规数字阅读/计算，不能只用“年报数量齐”关闭。行业篮子身份/权重还需明确。
* q05：原答案称缺三年价格。强价格版本实际已有 770 个交易日，2023-09-18 至 2026-10-12；SPY 有 2,515 个交易日，2016-10-10 至 2026-10-12。旧 memo 投影删除 `bars`，行情块只展示收盘价、市值、30 日 ADV。堵点部分在可引用输入，而非必须重新购买行情。
* q06：原答案把月度广告量、单价、Family 日活和第三方序列一起列为缺失。现有季度披露不能冒充月度；可说明可验证的实际频率与跟踪计划。如果选用的月度/专有数据不可得，保持精确缺项，不能用正文修正额度制造数据。
* q11：原答案将贝塔、期权 IV、对冲比例、组合授权一起列为未知。当前契约要求的是“研究建议”，不要求批准实盘。应分开研究情景和账户执行信息。无实际持仓也可提出有来源、假设明确的研究情景；不能推知真实持仓或编造期权参数。

## 新价格证据包的有限能力

新规则 `investment-memo-market-history:0.1` 从精确不可变价格版本生成一、二、三年窗口，以及最多六个来源日历已确认、无日期分歧的事件窗口。窗口以原始收盘价和源 `adj_close` 分开复算；回报采用精确有理数算术后以 HALF_UP 显示六位小数。事件窗口为事件前一个交易日到事件起第三个交易日，不作因果断言。缺端点、复权价格、同日期基准或有效日期时不造数。

有限 supplement 上限 8,000 字节，优先三年窗口与最近已确认事件；保留原有素材选择及全部既有引用。被省略的窗口数量及 hash 保留在投影证明中。模型调用原硬输入/费用门不变；原始日线不进入提示。发布、正文校验与维护重放从精确原版本重建新引用，不依赖 caller 自报值。旧素材/提示及原权限、已付回答、未知费用保留。

真实冻结 META/EPAM 输入的离线投影各保留三年窗口与一个已确认事件窗口，原 83/88 个可引用素材没有被挤掉；提示为 107,006/109,563 字节，仍小于既有 128,000 字节调用门。没有执行新模型、核验或正式报告写入。有限窗口尚不能证明 META 所要求的法律费用/模型发布/资本开支调整三年事件集合已完整；这些精确事件仍需正常来源补齐。
