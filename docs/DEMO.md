# Dalton 正式演示使用说明

> **当前状态（2026-09-13）：** R24 已安装、通过持续健康观察并正式发布；真实 UI、五家公司导出和一次真实 Ask 已通过。页面刚启动并生成第一次投影时可能暂缓；随后正常加载。完整研究上下文的 Ask 当前约需一分钟，请保持页面打开并等待处理状态结束。

## 打开研究台

在已获授权、连接同一 Tailscale 网络的设备上打开：

<https://everflowdemac-mini.taild2c767.ts.net:8793/>

页面展示 Dalton 已积累的真实研究数据和当前研究状态。建议按下面的顺序完成一次演示。

另有一个无需进入交互研究台的公开只读入口：

<https://eve.lumos.space/dalton/>

公开页面是定期更新的静态工作监督台，适合快速查看总任务、最近工作、模型使用、能力状态和最新产物。它不能打开公司详情、提问或生成下载文件；完整演示仍应使用上面的 Tailscale 研究台。

## 演示路线

1. **查看研究目标**

   首页首先展示当前研究目标、研究问题、研究计划和五家公司的阶段进度。这里适合说明系统正在研究什么，以及每家公司目前走到哪一步。

2. **打开公司详情**

   点击任意一家公司的卡片，进入公司研究详情。依次查看“概览”“证据”“模型”“事件”和“产物”页签，可以看到该公司的资料、结论、模型状态和已发布研究成果。

3. **查看模型表**

   在“模型”页签点击“看模型表”。已有模型的公司会显示当前版本、关键假设、结果和仍未满足的条件；尚未形成模型的公司会明确显示原因。

4. **查看和下载研究产物**

   在“产物”页签查看已有的初步筛选、公司档案或投资备忘录。点击“下载 HTML 报告”可取得便于阅读的研究报告；已有当前模型时，也可点击“下载 Excel 模型”取得工作簿。导出文件会保留来源、版本、未完成项和审批状态。

5. **查看研究日志**

   返回主页面并打开“研究日志”，查看系统近期完成、拒绝、等待或正在推进的研究工作。

6. **随时提问**

   打开“随时提问”，可围绕当前研究提出问题。回答以系统已经核实并入库的结论为依据；证据不足时，页面会直接说明缺口。一次完整问答当前通常需要约一分钟，提交后请等待页面显示完成结果。

## 演示边界

本演示使用真实既有数据，因此不同公司的完成度会有差异。部分研究阶段、模型和产物仍在持续推进；明确显示“未发布”“资料不足”或“等待”的状态属于当前真实结果。

这次演示用于展示已经可用的研究台流程，不表示 Dalton 规划中的所有能力都已完成。Guidepoint 和公司 Wiki 的后续激活不属于当前已上线能力。
